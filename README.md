Nome do projeto

Academia do eduzão e do luizão

Problema

Academias muitas vezes utilizam planilhas ou anotações para controlar alunos e treinos, o que dificulta a organização e o acompanhamento das atividades. O sistema tem como objetivo centralizar o cadastro de alunos e o gerenciamento de treinos, tornando o processo mais prático e organizado.

Público-alvo
Alunos da academia.
Instrutores e administradores da academia.
Funcionalidades iniciais
Cadastro de alunos.
Cadastro de instrutores.
Cadastro de treinos.
Associação de treinos aos alunos.
Consulta dos treinos de cada aluno.
Atualização de treinos.
Exclusão de alunos e treinos.
Pesquisa de alunos por nome.
Histórias de usuário
Eu, como aluno, quero visualizar meus treinos, para saber quais exercícios devo realizar.
Eu, como instrutor, quero cadastrar alunos, para manter o controle dos clientes da academia.
Eu, como instrutor, quero cadastrar treinos, para montar programas de exercícios personalizados.
Eu, como instrutor, quero associar um treino a um aluno, para que ele tenha acesso ao seu plano de exercícios.
Eu, como instrutor, quero atualizar um treino, para acompanhar a evolução do aluno.
Eu, como instrutor, quero remover treinos antigos, para manter o sistema organizado.
Eu, como administrador, quero cadastrar instrutores, para controlar quem pode acessar o sistema.
Eu, como administrador, quero pesquisar alunos, para localizar rapidamente seus dados.
Eu, como administrador, quero excluir alunos inativos, para manter o cadastro atualizado.
