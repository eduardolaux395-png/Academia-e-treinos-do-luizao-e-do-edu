# Academia-e-treinos-do-luizao-e-do-edu
Pilares de Funcionamento

Controle de Acesso:Bloqueia automaticamente a catraca de alunos inadimplentes.

Gestão Financeira: Automatiza cobranças recorrentes no cartão de crédito.

Prescrição de Treinos: Permite criar fichas de exercícios digitais.

Aplicativo do Aluno: Centraliza visualização de treinos, evolução e pagamentos.

Avaliação Física: Armazena dados de anamnese e composição corporal.
